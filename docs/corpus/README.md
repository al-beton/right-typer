# English practice corpus

The adaptive curriculum ships 1,474 everyday words from pinned ESDB/SCOWL, with 34 designated original starter words. The initial `enarit` pool contains 45 words. This British-spelling English curriculum is shared by every physical keyboard profile.

`provenance.json` records the upstream revision, extraction commands and selection digest; `editorial-exclusions.json` records rejected entries. The distributed notice is included at `public/licenses/ESDB-NOTICE.txt`. No keybr code or data is used.

Runtime content lives in `src/curriculum/corpus.json`; `fallback-pools.json` supplies finite, same-level target pools. Punctuation uses the same base word ID. Selection persists IDs and bounded evidence, not typed transcripts or camera data. Curriculum tests validate every prefix and review rotation.

The shared progress foundation intentionally omits the follow-on metrics inspector, export controls and daily active-time ledger (ALO-280).
