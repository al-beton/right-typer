# ALO-259 wordmark review

Open `wordmarks.html` on the app or PR preview. Add `?name=bright` to start
with Bright Typer; the selector updates the shareable URL. The project, document
title, default header and saved settings remain Right Typer. The gallery does not
load the practice app or start a camera.

Four editable CSS text options show enlarged and at the existing 22px header
size, on the actual #fafafa app background:

1. Sequential finger colours, wrapping after eight letters.
2. Monospace sequence with both thumb colours in the word gap.
3. Ink text with sequential colour underlines and a thumb-colour space.
4. Actual Standard QWERTY per-letter finger mapping, explicitly separate from
   sequential branding and the user's selected keyboard profile.

All colour fills reference existing CSS variables. The requested red and lilac
positions currently contain rose (#f7b4c8) and cyan (#87dce0), respectively. This
PR preserves those tokens; changing the keyboard palette needs a separate decision.

## Verification

- TypeScript, 197 unit tests and production build pass.
- Browser visual review at 1280px and 390px; no horizontal overflow at 320px.
- Both names render in all eight specimens; selection updates the URL. Plain-text
  accessible names are exposed once per specimen, with decorative letters hidden.
- Colour alone is insufficient contrast: the pastel fills range about 1.3–1.9:1
  against #fafafa. A 1.4px ink stroke strengthens options 01/02/04; the outline
  is not a claim that their pastel fills meet WCAG text contrast. Option 03 has
  solid #20252b text (about 14.8:1), making it the strongest small-size choice.
- No browser errors observed in the gallery. No camera/hardware accuracy claim.
